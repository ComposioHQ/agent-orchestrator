Agent Orchestrator (AO) is the orchestration layer for parallel AI coding agents. It runs multiple coding agents — Claude Code, Codex, Cursor, Aider, OpenCode, and 18 more — in isolated git worktrees and tracks each one through a pull request lifecycle, automatically routing CI failures, review comments, and merge conflicts back to the right agent.

## How Agent Orchestrator works

AO wraps your existing AI coding agent CLIs with a supervision layer. When you add a project and spawn a session, AO:

<Steps>
  <Step>
    **Creates an isolated git worktree** for that session, keeping each agent's files and branches completely separate
  </Step>

  <Step>
    **Launches the selected coding agent** inside a terminal runtime (tmux or process)
  </Step>

  <Step>
    **Watches session state** — terminal activity, pull requests, CI status, and review feedback — in real time
  </Step>

  <Step>
    **Routes feedback automatically** — CI failures, requested changes, and merge conflicts go back to the right session
  </Step>

  <Step>
    **Notifies you** when a session needs attention or a PR is ready to merge
  </Step>
</Steps>

The result is a local control layer — agents still do the coding, AO keeps their workspaces, status, terminals, and feedback loops organized.

<Tip>
  **Pro tip:** Use `ao spawn 42 --model claude-3-7-sonnet` to override the default agent or model for a specific session.
</Tip>

## Get started

<Steps>
  <Step title="Download Agent Orchestrator">
    <p>Download the desktop app from [aoagents.dev/download](https://aoagents.dev/download) for macOS, Windows, or Linux. See [Installation](/installation) for prerequisites.</p>
  </Step>

  <Step title="Add your project">
    Open AO, add your repository, and let AO start the orchestrator session automatically.
  </Step>

  <Step title="Spawn a session">
    Use the dashboard or run `ao spawn 42` to start an agent session for a GitHub issue.
  </Step>

  <Step title="Watch the board">
    Monitor progress on the Kanban board. AO handles CI failures and review feedback automatically — you step in only when needed.
  </Step>
</Steps>

<Note>
  AO is open-source under the Apache 2.0 license. Your code never leaves your machine — all agent sessions run locally.
</Note>
